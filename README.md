\ 📖 À propos du projet



\*\*TogoEnglish Play\*\* est une application web éducative conçue pour accompagner l'introduction de l'enseignement de l'anglais au cours préparatoire (CP1 et CP2) au Togo, suite à l'adhésion du pays au Commonwealth en juin 2022.



Cette application transforme le programme officiel du Ministère en une expérience d'apprentissage interactive, accessible et engageante pour les élèves, les parents et les enseignants.



\ 🎯 Objectifs



\- ✅ Rendre l'apprentissage de l'anglais \*\*ludique et interactif\*\*

\- ✅ Faciliter l'\*\*accompagnement parental\*\* à la maison

\- ✅ Fournir aux \*\*enseignants\*\* des ressources pédagogiques complètes

\- ✅ Offrir un accès \*\*hors-ligne\*\* grâce à la technologie PWA

\- ✅ Respecter le programme officiel (6 unités, 20 semaines, 1h40/semaine)

\ 📚 Programme Officiel



\ Structure du cours

\- \*\*Niveau :\*\* Cours Préparatoire (CP1 \& CP2)

\- \*\*Âge :\*\* 6-8 ans

\- \*\*Volume horaire :\*\* 20 minutes/jour, 5 jours/semaine (1h40 total)

\- \*\*Durée :\*\* 20 semaines (6 unités + Pre-Unit)



\ Unités d'apprentissage

1\. 🏫 \*\*My School\*\* - Salutations, alphabet, objets de la classe

2\. 👨‍👩‍👧 \*\*My Identity\*\* - Famille, maison, école, couleurs

3\. 🍎 \*\*Food\*\* - Fruits, légumes, nourriture locale et mondiale

4\. ⚽ \*\*Physical Activities\*\* - Corps humain, sports, actions

5\. 🧼 \*\*Healthy Habits\*\* - Hygiène, santé, alimentation

6\. 🦁 \*\*Animals\*\* - Animaux domestiques et sauvages

\ 🚀 Technologies utilisées



\- \*\*Frontend :\*\* HTML5, CSS3, JavaScript (Vanilla)

\- \*\*Hébergement :\*\* GitHub Pages (gratuit, rapide, fiable)

\- \*\*PWA :\*\* Progressive Web App (installable sur mobile, mode hors-ligne)

\- \*\*Stockage :\*\* localStorage (pas de base de données, pas de serveur)

\- \*\*Vidéos :\*\* YouTube (intégrées via iframe)

\- \*\*Audio :\*\* Web Speech API (synthèse vocale pour la prononciation)
