📄 Guide de Déploiement

TogoEnglish Play - Programme officiel CP1 & CP2

Ministère des Enseignements Primaire, Secondaire et Technique du Togo

📱 1. Installation sur Android

1. Ouvrez Chrome sur le téléphone

2. Allez sur : https://cpefpa.github.io/togo-english-play/

3. Cliquez sur "Installer" quand la bannière apparaît

4. L'icône s'ajoute à l'écran d'accueil

🍎 2. Installation sur iPhone / iPad

1. Ouvrez Safari

2. Allez sur le lien de l'application

3. Appuyez sur le bouton Partager (carré avec flèche)

4. Choisissez "Sur l'écran d'accueil"

👩‍🏫 3. Guide pour l'Enseignant

  • Utilisez l'Espace Enseignants pour les fiches pédagogiques
  • Projetez les vidéos ou utilisez les flashcards hors-ligne
  • Emploi du temps : 20 min/jour, 5 jours/semaine (1h40 total)
  • 6 unités à couvrir sur 20 semaines

👨‍👩‍👧 4. Guide pour les Parents

  • Accompagnez votre enfant 10-20 minutes par jour
  • Regardez les vidéos ENSEMBLE
  • Répétez les mots et félicitez : "Very good!", "Well done!"
  • Les jeux fonctionnent même sans internet

🎮 5. Les 3 Mini-Jeux

  • 🧠 Mémoire : Retrouver les paires mot/emoji
  • 🔗 Association : Associer mot anglais et image
  • 🎤 Prononciation : Écouter, enregistrer, comparer
